Problema 12: Raíces de una ecuación cuadrática

Descripción: determinar las raíces reales de la ecuación ax² + bx + c = 0 usando el discriminante D = b² − 4ac.

Algoritmo:

  1. Leer a, b y c.
  2. Calcular D = b² − 4ac.
  3. Si D > 0: dos raíces, x = (−b ± √D) / 2a.
  4. Si D = 0: una raíz, x = −b / 2a.
  5. Si D < 0: no hay raíces reales.

Entrada: a, b, c. Salida: mensaje y raíces.

Problema 13: Estimar el valor de π

Descripción: π se estima con la expresión √( 6 · (1/1² + 1/2² + 1/3² + ... + 1/n²) ). Se compara el resultado con el valor real de π.

Algoritmo:

  1. Leer n.
  2. suma = 0.
  3. Con un bucle for, de k = 1 hasta n: suma = suma + 1/k².
  4. pi estimado = √(6 · suma).
  5. error = |π real − π estimado|.

Entrada: n (100, 10000, 1000000). Salida: π estimado, π real y error.
